# AG Grid Flex-Fill Fix: Radix TabsContent + Tailwind `flex` Conflict

## Problem

AG Grid instances inside Radix UI `TabsContent` components were not filling their available vertical space. Two symptoms were observed:

1. **Monthly Drill-Down tab** — grid rendered rows but left large empty space below
2. **Offender Analysis tab** — huge empty gap above the content, with the grid pushed to the bottom

## Root Cause

A CSS specificity conflict between Radix UI's tab hiding mechanism and Tailwind's `display` utilities.

### How Radix hides inactive tabs

Radix `TabsContent` uses the HTML `hidden` attribute to hide inactive tab panels:

```html
<!-- Active tab -->
<div data-state="active" class="flex-1 flex flex-col min-h-0">...</div>

<!-- Inactive tab — Radix adds the hidden attribute -->
<div data-state="inactive" hidden class="flex-1 flex flex-col min-h-0">...</div>
```

The `hidden` attribute sets `display: none` via the **browser's user-agent stylesheet**.

### How Tailwind overrides it

Tailwind's `flex` utility class sets `display: flex` as an **author stylesheet** rule. In the CSS cascade, author styles always beat user-agent styles. So:

```
User-agent:  [hidden] { display: none }     ← lower priority
Author:      .flex    { display: flex }      ← higher priority, WINS
```

The inactive `TabsContent` elements were never actually hidden. Both the active and inactive tab panels remained visible inside the flex container, splitting the available space between them.

### Visual effect

```
┌─────────────────────────────┐
│ Tab Header                  │
├─────────────────────────────┤
│                             │  ← Inactive tab (invisible content,
│   (empty space)             │     but still occupying flex space)
│                             │
├─────────────────────────────┤
│ Active tab content          │  ← Only gets ~50% of the space
│ (AG Grid squeezed here)    │
└─────────────────────────────┘
```

## Solution

Added `data-[state=inactive]:hidden` to every `TabsContent` that uses Tailwind's `flex` class. This Tailwind data-attribute variant generates a rule with higher specificity than the plain `flex` class:

```css
/* Generated by Tailwind — higher specificity wins */
[data-state=inactive].data-\[state\=inactive\]\:hidden {
  display: none;
}

/* Plain flex class — lower specificity */
.flex {
  display: flex;
}
```

### Files changed

**`src/components/tasks/tabs/DashboardTab.tsx`**

```tsx
// Before
<TabsContent value="drilldown" className="m-0 flex-1 flex flex-col min-h-0">
<TabsContent value="offenders" className="m-0 flex-1 flex flex-col min-h-0">

// After
<TabsContent value="drilldown" className="m-0 flex-1 flex flex-col min-h-0 data-[state=inactive]:hidden">
<TabsContent value="offenders" className="m-0 flex-1 flex flex-col min-h-0 data-[state=inactive]:hidden">
```

**`src/components/tasks/TaskDetailTabs.tsx`**

```tsx
// Before
<TabsContent value="dashboard" className="m-0 px-3 py-2 flex-1 min-h-0 flex flex-col">

// After
<TabsContent value="dashboard" className="m-0 px-3 py-2 flex-1 min-h-0 flex flex-col data-[state=inactive]:hidden">
```

### Additional fixes applied

Two other layout issues were resolved as part of this effort:

1. **`relative` + `absolute inset-0` pattern for AG Grid containers** — AG Grid needs its container to have concrete pixel dimensions. Flex-derived heights alone aren't always readable by AG Grid's internal sizing logic. Wrapping the grid in an absolutely-positioned inner div ensures the grid can measure its container:

   ```tsx
   <div className="flex-1 min-h-0 relative">
     <div className="absolute inset-0">
       <AgGridReact ... />
     </div>
   </div>
   ```

2. **Replaced `h-full` with `flex-1 min-h-0`** on components that are children of flex containers — CSS percentage heights (`height: 100%`) cannot resolve against a parent whose height is flex-computed. Using `flex-1 min-h-0` properly participates in the flex chain instead.

## General Rule

When using Radix UI `TabsContent` with Tailwind CSS, never put `flex`, `grid`, `inline-flex`, `inline-grid`, `block`, or `inline-block` directly on the `TabsContent` className without also adding `data-[state=inactive]:hidden`. Any Tailwind class that sets the `display` property will override Radix's `hidden` attribute on inactive tabs.

```tsx
// BAD — inactive tab stays visible
<TabsContent className="flex flex-col flex-1">

// GOOD — inactive tab properly hidden
<TabsContent className="flex flex-col flex-1 data-[state=inactive]:hidden">
```
